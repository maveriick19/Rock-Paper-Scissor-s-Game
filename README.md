# 🎮 Rock Paper Scissors Game

A simple and interactive Rock Paper Scissors game built using **HTML, CSS, and JavaScript**. The player competes against the computer, and the score updates dynamically after each round.

---

## 🚀 Features

- 🎯 Interactive UI with buttons
- 🤖 Computer generates random moves
- 📊 Live score tracking
- ⚡ Instant result display
- 🎨 Clean and simple design

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## 📂 Project Structure

```
├── index.html
├── index.css
└── index.js
```

---

## ▶️ How to Run

1. Download or clone the repo
2. Open `index.html` in browser
3. Start playing 🎉

---

## 🧠 How It Works

- User clicks Rock / Paper / Scissors
- Computer generates a random move
- JS compares both choices
- Result and score update instantly

---

## 📜 Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choice → Tie
